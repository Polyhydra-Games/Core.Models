## Mapped-Frontier Development

- Use the `mapped-frontier-development` Codex skill for MFD/STDD, Phase 0,
  build-packet, or approval-brief work.
- Keep GitHub issue-first traceability, immutable approval evidence, deviation
  return, exact-head review, CI, release authority, and live-proof boundaries.
- The Global DevOps GitHub-Kanban Contract remains higher precedence for
  infrastructure, security, deployment, GitOps, and service work.
- A small change may opt out only when its GitHub issue records the rationale.
