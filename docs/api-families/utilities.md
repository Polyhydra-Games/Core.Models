# Utilities

The root namespace contains cache helpers, one-time and toggle booleans, timestamp and port-reply types, content-type helpers, and Reactive Extensions-based observable helpers. `Settings` contains typed setting models. `Serialization` contains JSON, XML, and HTTP serialization helpers.

Some utilities accept interfaces from the `PolyhydraGames.Core.Interfaces` dependency. Consumers should reference that package when using those APIs.
